Sobre o Arch Linux

O Arch Linux é uma distribuição Linux independente e minimalista, lançada em 2002. Segue a filosofia KISS (Keep It Simple, Stupid): o sistema é construído pelo próprio usuário, componente a componente, do zero.

Por ser rolling release, o Arch não tem versões fixas — o sistema é sempre atualizado para o software mais recente através do gerenciador de pacotes pacman, sem necessidade de reinstalação.

O AUR (Arch User Repository) é um dos maiores repositórios comunitários do Linux. A ArchWiki é considerada a melhor documentação do ecossistema Linux — útil até para usuários de outras distribuições.
