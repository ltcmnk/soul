Política de Privacidade

Última atualização: junho de 2025

Compromisso com a Privacidade

O SOul coleta apenas os dados estritamente necessários para o funcionamento da plataforma. Nenhuma informação é vendida, repassada ou utilizada para fins comerciais. Este projeto não possui fins lucrativos.

1. Quem Somos

O SOul é um projeto acadêmico desenvolvido por estudantes do curso de Desenvolvimento de Sistemas. Opera em ambiente local (localhost) durante o período de avaliação, sem infraestrutura de produção em nuvem. Esta política descreve como os dados fornecidos pelos usuários são tratados dentro desse contexto.

2. Dados Coletados

A tabela abaixo detalha exatamente quais dados são coletados, onde são armazenados e por quê:

Dado Armazenamento Finalidade
Nome MySQL (local) Identificação na interface
E-mail MySQL (local) Login e identificação única
Senha MySQL (hash bcrypt) Autenticação — nunca armazenada em texto puro
Respostas do quiz localStorage + MySQL (JSON) Gerar e registrar a recomendação
Sistemas favoritos localStorage + MySQL Exibição personalizada dos favoritos
Histórico de recomendações MySQL (local) Registro de resultados anteriores do usuário
Preferência de tema localStorage Manter tema claro/escuro entre sessões

3. O Que Não Coletamos

O SOul não coleta:

  • Endereço IP ou localização geográfica;
  • Cookies de rastreamento ou identificadores publicitários;
  • Dados de navegação ou comportamento fora da plataforma;
  • Informações de dispositivo além das necessárias para a sessão;
  • Dados biométricos ou financeiros de qualquer natureza.

4. Compartilhamento de Dados

Os dados dos usuários não são compartilhados com terceiros, anunciantes ou parceiros comerciais. As únicas "terceiras partes" envolvidas no processamento são:

  • Ollama (local): as respostas do quiz são enviadas ao modelo de IA que roda na própria máquina do usuário/servidor. Nenhum dado é enviado a servidores externos;
  • Font Awesome (CDN): carregamento de ícones via CDN público — sem dados de usuário transmitidos.

5. Segurança dos Dados

As seguintes medidas de segurança são adotadas:

  • Senhas armazenadas exclusivamente como hash bcrypt (via password_hash do PHP);
  • Banco de dados MySQL operando localmente, sem exposição à internet;
  • Comunicação entre frontend e backend restrita ao ambiente local;
  • Nenhum dado sensível trafega em texto puro nas requisições da API.

Por tratar-se de um projeto acadêmico em ambiente de desenvolvimento, não há certificado SSL/TLS ativo. Recomenda-se não reutilizar senhas pessoais nesta plataforma.

6. Retenção de Dados

Os dados são mantidos enquanto a conta do usuário existir no banco de dados. Como o projeto opera em ambiente local, os dados são armazenados exclusivamente na instância MySQL da máquina onde o sistema está sendo executado. Não há backup automatizado em servidores externos.

7. Direitos do Usuário

Em consonância com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), o usuário tem direito a:

  • Acesso: saber quais dados seus estão armazenados;
  • Correção: solicitar atualização de dados incorretos;
  • Exclusão: solicitar a remoção de sua conta e dados associados;
  • Portabilidade: receber seus dados em formato estruturado;
  • Revogação: retirar consentimento a qualquer momento.

Para exercer qualquer desses direitos, entre em contato pelos canais indicados na seção 9.

8. Menores de Idade

O SOul não é destinado a menores de 13 anos. Usuários entre 13 e 18 anos devem obter consentimento de um responsável legal antes de criar uma conta. Caso identifiquemos o cadastro de menor sem autorização, os dados serão excluídos imediatamente.
